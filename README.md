## 📌 About

This repository is my personal **Spring learning lab**. Instead of only
learning concepts theoretically, I explore them by writing code,
building small demos, experimenting with configurations, and observing
how Spring works behind the scenes.

The repository will continue to grow as I learn more topics across the
Spring ecosystem.

> Learn the concept → Write the code → Experiment → Understand what
> happens under the hood.

## ▶️ Running the Projects

Most folders are independent practice projects. To explore one:

1.  Clone the repository:

    ``` bash
    git clone https://github.com/samva123/Spring.git
    ```

2.  Open the repository in your IDE.

3.  Navigate to the concept/project you want to explore.

4.  Open its `pom.xml` (if it is a Maven project) and allow Maven to
    load dependencies.

5.  Run the project's main class or the example you want to test.

> Some folders may have their own setup requirements as the repository
> grows.
